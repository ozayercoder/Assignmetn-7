## 📖 About The Project

Briefly explain:
- This is a real time market price  website of goods in Bangladesh
- I practice Next JS routing, React context API and many more interesting topics via this project.

---

## ✨ Features

- You can Sign in or Sign up to explore 
- You can see your profile and update your profile
- You can see prices of good in different markets
- You can see statistics of products prices in bd
- The website is fully resposive
- It has cool user interface
